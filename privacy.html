Data we access This application accesses, exclusively through TikTok's official authentication (OAuth 2.0), the following data from the connected account: - Basic profile information (display name and profile photo), through the `user.info.basic` scope, used only to identify the connected account. - Video publishing permission, through the `video.publish` scope, used exclusively to publish videos that the owner requests. How data is used Authentication data (access token) is used only to allow the owner to publish videos to their own account, through a private automation (n8n). The data is not used for any other purpose. 3. Data sharing We do not share, sell, or transfer any account or content data with third parties. Authentication data is stored privately, only within the owner's automation environment. 4. Official authentication This application uses exclusively TikTok's official OAuth 2.0 flow for authentication. We never store TikTok login passwords or credentials. 5. How to remove access The account owner can revoke this application's access at any time, directly through TikTok, at: **Settings and privacy > Security and login permissions > Connected apps**, selecting this application and choosing "Remove access." 6.
