Privacy Policy

Last updated: September 3, 2026

1. Data we access

This application accesses, exclusively through TikTok's official authentication (OAuth 2.0), the following data from the connected account:

  • Basic profile information (display name and profile photo), through the user.info.basic scope, used only to identify the connected account.
  • Video publishing permission, through the video.publish scope, used exclusively to publish videos that the owner requests.

No other data is collected. We do not access follower lists, messages, comments, or any data belonging to other users.

2. How data is used

Authentication data (access token) is used only to allow the owner to publish videos to their own account, through a private automation (n8n). The data is not used for any other purpose.

3. Data sharing

We do not share, sell, or transfer any account or content data with third parties. Authentication data is stored privately, only within the owner's automation environment.

4. Official authentication

This application uses exclusively TikTok's official OAuth 2.0 flow for authentication. We never store TikTok login passwords or credentials.

5. How to remove access

The account owner can revoke this application's access at any time, directly through TikTok, at: Settings and privacy > Security and login permissions > Connected apps, selecting this application and choosing "Remove access."

6. Contact

For questions about this Privacy Policy, please contact: raphax2@hotmail.com

Política de Privacidade

Última atualização: 03/09/2026

1. Dados que acessamos

Este aplicativo acessa, exclusivamente via autenticação oficial do TikTok (OAuth 2.0), os seguintes dados da conta conectada:

  • Informações básicas de perfil (nome de exibição e foto de perfil), por meio do escopo user.info.basic, usadas apenas para identificar a conta conectada.
  • Permissão de publicação de vídeos, por meio do escopo video.publish, usada exclusivamente para publicar os vídeos que o próprio proprietário solicitar.

Nenhum outro dado é coletado. Não acessamos lista de seguidores, mensagens, comentários ou qualquer dado de outros usuários.

2. Como os dados são usados

Os dados de autenticação (token de acesso) são usados apenas para permitir que o próprio proprietário publique vídeos em sua própria conta, por meio de uma automação privada (n8n). Não há uso dos dados para nenhuma outra finalidade.

3. Compartilhamento de dados

Não compartilhamos, vendemos ou transferimos nenhum dado de conta ou conteúdo com terceiros. Os dados de autenticação ficam armazenados de forma privada, apenas no ambiente de automação do proprietário.

4. Autenticação oficial

Este aplicativo utiliza exclusivamente o fluxo oficial de OAuth 2.0 do TikTok para autenticação. Não armazenamos senha ou credenciais de login do TikTok em nenhum momento.

5. Como remover o acesso

O proprietário da conta pode revogar o acesso deste aplicativo a qualquer momento, diretamente pelo TikTok, em: Configurações e privacidade > Segurança e permissões de login > Aplicativos conectados, selecionando este aplicativo e escolhendo "Remover acesso".

6. Contato

Em caso de dúvidas sobre esta Política de Privacidade, entre em contato através de: raphax2@hotmail.com
