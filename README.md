Project Overview
Last updated: 09/03/2026

What this project does
This is a personal automation project that publishes video content to the owner's own TikTok account(s). Publishing is triggered manually by the owner, on demand — there is no scheduled, autonomous, or mechanical posting activity, and no interaction of any kind with other TikTok users or accounts.

How it works
The project uses n8n (a private workflow automation tool) connected to TikTok's official Content Posting API through OAuth 2.0. When the owner wants to publish a video:

The owner starts the workflow with the video file and post details.
n8n authenticates with TikTok using the account's authorized access token.
The video is uploaded and published directly to the owner's own TikTok account.
No third-party accounts are connected, and no content is posted without the owner's direct action.

Scopes used
user.info.basic — to identify the connected account.
video.publish — to publish the video directly to the account.
Who uses this
This project is for personal use only. It is not distributed to other users and does not manage or post to accounts other than the owner's own.

Visão Geral do Projeto
Última atualização: 03/09/2026

O que este projeto faz
Este é um projeto pessoal de automação que publica conteúdo em vídeo na(s) própria(s) conta(s) do TikTok do proprietário. A publicação é disparada manualmente pelo proprietário, sob demanda — não há postagem agendada, autônoma ou mecânica, nem qualquer tipo de interação com outros usuários ou contas do TikTok.

Como funciona
O projeto usa o n8n (uma ferramenta privada de automação de fluxos de trabalho) conectado à API oficial de Content Posting do TikTok via OAuth 2.0. Quando o proprietário quer publicar um vídeo:

O proprietário inicia o fluxo com o arquivo de vídeo e os detalhes do post.
O n8n se autentica no TikTok usando o token de acesso autorizado da conta.
O vídeo é enviado e publicado diretamente na própria conta do proprietário.
Nenhuma conta de terceiros é conectada, e nenhum conteúdo é publicado sem ação direta do proprietário.

Scopes utilizados
user.info.basic — para identificar a conta conectada.
video.publish — para publicar o vídeo diretamente na conta.
Quem usa
Este projeto é de uso exclusivamente pessoal. Não é distribuído para outros usuários e não gerencia nem publica em contas além da do próprio proprietário.
